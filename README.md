# WTWR (WHAT TO WEAR)

A weather-based clothing recommendation app that suggests what to wear depending on the current weather conditions.

## Features

- Displays real-time weather data
- Suggests clothing items based on temperature
- Add new clothing items
- Preview clothing items in a modal
- Responsive layout

## Technologies Used

- React
- JavaScript
- CSS
- Vite

## Deployment

The application is deployed on a Google Cloud virtual machine using Nginx and PM2, with HTTPS enabled for secure access.
